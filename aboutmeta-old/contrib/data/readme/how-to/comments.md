### Magic comments to use

The following complete template show you how to structure the code in the `Python` file, where the `TEST` section only makes sense for data classes with extra action.


~~~python
#!/usr/bin/env python3

...


# --------------- #
# -- CONSTANTS -- #
# --------------- #

...


# ----------------------------- #
# -- NAME OF YOUR DATA CLASS -- #
# ----------------------------- #

...

# ----------- #
# -- TESTS -- #
# ----------- #

if __name__ == "__main__":
    ...
~~~

##### Languages

You can specify a language using the [ISO 639 standard][1], then, if needed, add a country using the [ISO 3166 standard][2].
The default language is `en_GB` for British English.
You can type either `fr` if you do not wish to specify France, or `fr_BE` to indicate Belgian French.


[1]: https://en.wikipedia.org/wiki/ISO_639
[2]: https://en.wikipedia.org/wiki/ISO_3166

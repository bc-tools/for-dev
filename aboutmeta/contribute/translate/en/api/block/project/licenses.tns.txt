This block serves to give a license (which is a best practice).
You can used the folowing keys.

    1. ''code'' is for the project license.

    1. ''manual'' allows, in the case of a code-type project, the
       selection of a specific user manual license.


note::
    The license names proposed by the cf::''''SPDX'' SPDX License
    List ; https://spdx.org/licenses/'' are taken into account,
    with a certain degree of flexibility: for example, you can type
    ''gpl 3.0+'' and ''cc by nc 4.0'' instead of ''GPL-3.0+'' and
    ''CC-BY-NC-4.0''.


Here is a fictitious example.

yaml::
    licenses:
      code  : gpl 3.0+
      manual: cc by nc 4.0

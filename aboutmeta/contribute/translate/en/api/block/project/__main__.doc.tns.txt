This block allows to describe a numerical project from a technical
point of view.


Here is a fictitious example identifying a code project (the case
of a document-type project is similar)."

yaml::
    project:
      version: 0.0.0-beta.1
      date   : 2025-06-27

      acronym : "[@]bout [Desc]ription"
      codename: a_desc
      desc    : The project ''@Desc'' is...

      authors:
        - Ada, Lovelace  [ada.babbage.computer@paper.org]
          (Victorian Applied Mechanical Informatic Institute)
        - Jean, Louis, Krivine  [jl-krivine@compile.brain]
        - Torvalds
          (Sacred Kernels Department)
        - William, Justme

      contribs:
        - Alan, Turing  [alan.turing@enigma.uk]
          (Institut de Cryptographie Avancée)
        - Donald, Knuth  [donald.knuth@texmath.net]
          (University of TeX-as Typography)

      urls:
        home  : https://github.com/bc-tools/for-dev
        dev   : https://github.com/bc-tools/for-dev/tree/main/aboutmeta
        issues: https://github.com/bc-tools/for-dev/issues

      licenses:
        code  : gpl 3.0+
        manual: cc by nc 4.0

      langs:
        doc   : fr
        manual: fr

      require:
        - python3
        - latex

      keywords:
        - metadata
        - coding
        - writing


note::
    For a document-type project, the ''project.codename'' key is
    no longer usable and must be replaced by ''project.doctitle''
    (a document must have a title). By default, the project is
    considered a code project.

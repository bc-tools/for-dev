How to propose a new data object?
---------------------------------

> ***NOTE.*** *Before adding a new data type class, make sure that a ready-made solution does not already exist. For reference, the `date` and `sem_version` parsers implemented by `aboutmeta` use `datetime.date` and `semver.Version` respectively. If no reliable and well-established solution is available, the new data type class must comply with the rules described in the following sections.*

Proposing new data objects
--------------------------

> ***IMPORTANT.*** *Before adding a new data type class, make sure that a ready-made solution does not already exist. For reference, `YMD` dates and semantic version numbers are handled by `datetime.date` and `semver.Version` respectively, two well-established tools. If no reliable, established solution is available, the new data type class must comply with the rules described in the following sections.*


> ***NOTE.*** *A data type class can expose its own small DSL. For reference, see `contrib/data/code/acronym.py`file.*

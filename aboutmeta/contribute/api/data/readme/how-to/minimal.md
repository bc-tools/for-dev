### Minimum requirements

Let’s start with a minimal example of a data type class that only stores height and weight data. This can be done as follows.

~~~python
from aboutmeta.core.data_manager import DataManager
from aboutmeta.core.validate     import validate_type


# ---------- #
# -- DATA -- #
# ---------- #

class Biometric(DataManager):
    height: float
    weight: float

# Mandatory basic data type validation.
    def __post_init__(self) -> None:
        validate_type(
            data_name      = 'height',
            data           = self.height,
            types_expected = float,
        )

        validate_type(
            data_name      = 'weight',
            data           = self.weight,
            types_expected = float,
        )


# ----------- #
# -- TESTS -- #
# ----------- #

if __name__ == "__main__":
# Doing tests is the best!
    ...
~~~


Here are the constraints to follow for methods.

  1. A basic validation of the data type should be carried out. Behind the scenes, `validate_type` relies on the `isinstance` function.

  1. `__str__`  and `__repr__` are automatically generated by the `dataclasses.dataclass` to provide a human-readable string representation of a `DataManager` instance. **You do not need to implement it.**

  1. The optional `normalize` method allows to normalize data.

  1. The optional `validate` method achieves data validation.


> ***WARNING.*** *`DataManager` exposes the `data_pb` attribute for validation information (see the `validate` method below). Never use the attribute `data_pb` to store data!*


> ***IMPORTANT.*** *Providing a few tests is essential; they will be integrated into the final project's unit test suite.*

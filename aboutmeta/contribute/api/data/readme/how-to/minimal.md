### Minimum requirements

Let's start with a minimal dummy example of a dataclass that stores only height and weight data.


~~~python
from aboutmeta.core.data_manager import DataManager
from aboutmeta.core.validate     import validate_type

# ---------- #
# -- DATA -- #
# ---------- #

class Biometric(DataManager):
    height: float
    weight: float

# Mandatory basic data type validations.
    def __post_init__(self) -> None:
        for dn, d, te in [
            ('height', self.height, float),
            ('weight', self.weight, float),
        ]:
            validate_type(
                data_name      = dn
                data           = d,
                types_expected = te,
            )

# ----------- #
# -- TESTS -- #
# ----------- #

if __name__ == "__main__":
# Doing tests is the best!
    ...
~~~


Here are the constraints to follow.

  1. Basic data type validation must be performed inside the `__post_init__` method using `validate_type`, which relies on the built-in `isinstance` function.

  1. `__str__` and `__repr__` are automatically generated by `dataclasses.dataclass` to provide a human-readable string representation of a `DataManager` instance. **You do not need to implement them.**

  1. The optional `normalize` method normalizes attribute values.

  1. The optional `validate` method performs data validation.


> ***WARNING.*** *`DataManager` exposes the `data_pb` attribute for validation details (see the `Validate data` section below). Never use `data_pb` to store data!*


> ***IMPORTANT.*** *Writing tests is essential, as they will be integrated into the final project's test suite.*

Adding new translations
=======================

What can be done?
-----------------

The `aboutmeta` project requires the translation of its user manual and technical documentations.


Where to start?
---------------

The `en` folder is the one managed by the project. It should therefore be copied to propose a new translation.


How to proceed?
---------------

The translations are done via `tns` files (the syntax remains natural, even though `tns` is not public yet).

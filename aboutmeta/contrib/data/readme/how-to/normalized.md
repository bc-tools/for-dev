### Normalize the standard version

The special no-argument method `normalized` must return a string **normalized** version of the `std` attribute, **without modifying any attributes**. This method is used in rare cases where initial normalization is not straightforward: the `url.URl` class is a good example of a practical case.


> ***IMPORTANT.*** *As not all normalization systems are considered 100% reliable, the `normalized` method is useful for terminal sessions.*

==
22  (0.0.0-beta.10)
==

-----
:new:
-----

[[:api:]]
\Toc: five kinds of paths can be indicated. Only the parser is functional at the moment.

    1) A relative path to a file.

    1) A relative path to a folder with an path::''about.yaml'' file to indicate a sub yaml::''toc'' block to use.

    1) A \glob pattern to obtain a list of file paths sorted "naturally" by the ''natsort'' module.

    1) A \regex pattern to obtain a list of file paths directly inside the parent folder, the list being sorted "naturally".

    1) A \regex pattern with a recursive search can also be used.


--------
:update:
--------

[[:doc:]]
\Readme: explanations about how the new yaml::''toc'' works now.


--------
:fordev:
--------

[[:test:]]
Tests for the new ''toc'' parser has been build.

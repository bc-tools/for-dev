[[:tech:]]
Here are the \chges made.

    1) \yaml \cfg files.

        + Magic decorators ''*'' (zero or more) and ''+'' (at least one) must end the names and be preceded by a space.

        + For keys, it is possible to use a syntax like yaml::''key-1-a , key-1-b | key-2'' with higher priority for the pipe.

    1) \python data and parser files: magic comments have been simplified a lot (this has been made possible by the fact that parsers and post-rpocessing tools are put inside the same \python file).


    1) In the contributions folder, addition of unit tests for data and parser codes, as well as \yaml test files to validate expected structures for blocks.

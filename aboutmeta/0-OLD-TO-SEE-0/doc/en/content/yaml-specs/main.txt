===========
YAML \specs
===========

In this section, we present all level ''1'' blocks and keys proposed by \thisproj.


In the following fictive example, the level ''1'' blocks are named yaml::''block-1'', yaml::''block-2'', and yaml::''block-3'', whereas yaml::''main-key'' is a level `1` key.

yaml::
    main-key: Not only level 1 blocks!

    block-1:
      sub-block:
        Some text
        on several lines...

    block-2:
      - element 1
      - element 2

    block-3:
      - key-1: val-1
      - key-2: val-2
      - key-3: val-3


Here are the **conventions that will be used in our explanations**.

  1. The concept of \attr will refer to a block, a key, etc.

  1. A virtual pointed path like yaml::''block-3.key-1'' refers to the key yaml::''key-1'' of the block yaml::''block-3''.


note::
    If you are unfamiliar with the general syntax of \yaml, the cf::''Wikipedia article YAML ; https://wikipedia.org/wiki/YAML'' is a good place to start.


important::
    Technically, \yaml files are read securely by treating all \vals as simple character strings.
